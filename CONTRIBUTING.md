# Contributing to AEIRO

Thank you for your interest in the work of the Africa Energy Information Research Organization (AEIRO). We welcome contributions from researchers, engineers, data scientists, students and practitioners who share our goal of reliable, evidence-based energy delivery in Africa.

## Ways to contribute

- **Report a data error.** If you find an incorrect figure, a broken source or an inconsistency in our data, open an issue using the **Report a data error** template in the relevant repository.
- **Report a problem with code or tools.** Use the **Report a problem** issue template.
- **Improve documentation.** Corrections and clarifications to READMEs, methodology notes and guides are always welcome.
- **Contribute code or analysis.** Fix a bug, improve a model or add a feature through a pull request (see below).
- **Share data or research.** If you have datasets, reports or case studies that could strengthen our work, email [info@aeiro.org](mailto:info@aeiro.org). Please do not upload third-party or sensitive data directly to a repository.

## Before you start

1. Read our [Code of Conduct](CODE_OF_CONDUCT.md).
2. Check existing issues and pull requests to avoid duplicating work.
3. For larger changes, open an issue first to discuss your idea with the team.

## Making a pull request

1. Fork the repository and create a branch with a short, descriptive name (for example `fix-generator-cost-units`).
2. Keep each pull request focused on one change.
3. Write clear commit messages that explain what changed and why.
4. Update documentation and cite sources for any new data or figures.
5. Fill in the pull request template and link any related issue.
6. A maintainer will review your pull request. We may ask for changes before merging.

## Data and research standards

- **Cite every source.** Every dataset, figure or claim should be traceable to a source (publication, agency, utility report or AEIRO fieldwork).
- **Document your method.** Explain how data was collected, cleaned or modeled so others can reproduce it.
- **Protect privacy.** Never include personal information, customer-level utility data or confidential documents.
- **Respect licenses.** Only contribute data and code you have the right to share.

## Licensing

By contributing, you agree that your contribution will be released under the license of the repository you are contributing to (see its `LICENSE` file).

## Questions

See [SUPPORT.md](SUPPORT.md) or contact us at [info@aeiro.org](mailto:info@aeiro.org).
