# Security Policy

AEIRO takes the security of its code, data and platforms, including the AEIRO Data Hub, seriously.

## Reporting a vulnerability

**Please do not report security issues in public GitHub issues.**

If you discover a security vulnerability, or find sensitive information (such as credentials or personal data) exposed in any AEIRO repository, email [info@aeiro.org](mailto:info@aeiro.org) with the subject line **"Security report"** and include:

- A description of the issue and where you found it
- Steps to reproduce it, if applicable
- The possible impact

We will acknowledge your report as soon as possible, keep you informed while we investigate, and credit you once the issue is resolved if you wish.

## Supported versions

We address security issues in the latest version of each actively maintained repository.
