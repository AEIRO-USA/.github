# Getting Help

- **Found an error in our data?** Open an issue in the relevant repository using the **Report a data error** template.
- **Problem with code or a tool?** Open an issue using the **Report a problem** template.
- **Partnerships, data sharing or general enquiries:** email [info@aeiro.org](mailto:info@aeiro.org).
- **Volunteering or joining the team:** see [aeiro.org/support](https://aeiro.org/support/).
- **Security issues:** follow our [Security Policy](SECURITY.md). Please do not post them publicly.

Learn more about our work at [aeiro.org](https://aeiro.org).
